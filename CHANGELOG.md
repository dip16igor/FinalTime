# Changelog

Все заметные изменения в этом проекте будут документированы в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и проект следует [Semantic Versioning](https://semver.org/lang/ru/).

## [1.5.0] - 2025-08-08

### Добавлено
- **Название соревнований** — поле в параметрах, сохраняется в state.json.
- Название используется в заголовке Excel-отчёта и в именах файлов: `Report_<название>_v1.5.0.xlsx/csv`.
- Панель «Параметры соревнований» перекомпонована: название → дата + регистрация → категории.

## [1.4.0] - 2025-08-08

### Добавлено
- **Меню «Чистая загрузка»** — полный сброс состояния (участники, финиши, категории, таймер, state.json).
- **Кнопка «Загрузить регистрацию»** в верхней панели + отображение названия файла (аналогично категориям).
- **Сохранение пути к файлу категорий** в state.json — категории восстанавливаются при перезапуске.
- **Сохранение даты соревнований** в state.json — дата восстанавливается при перезапуске.

## [1.3.0] - 2025-08-07

### Изменено
- **Переименование приложения**: `ChronoJudge` → `FinalTime`.
- Пакет переименован: `chronojudge/` → `finaltime/`.
- Все внутренние импорты обновлены.
- Имя exe: `FinalTime_v1.3.0.exe`.
- Папка данных: `%APPDATA%/FinalTime/`.
- Файлы отчётов: `Report_FinalTime_v1.3.0.xlsx/csv`.

## [1.2.0] - 2024-12-19

### Добавлено
- **Поло-возрастные категории**: поддержка загрузки категорий из Excel-файла.
- **Дата рождения и пол** участников: новые колонки в файле регистрации (D - Дата рождения, E - Пол).
- **Расчёт возраста**: количество полных лет на дату соревнований.
- **Категория в таблице**: колонка "Категория" с ярлыками (М40, Ж25, МОбщ, ЖОбщ).
- **Дата соревнований**: выбор даты в UI для корректного расчёта возраста.
- **Экспорт с категориями**: Excel и CSV отчёты включают колонку категории.
- **CategoriesImporter**: загрузка категорий (название, пол, мин/макс возраст, общий зачёт).

## [1.1.1] - 2024-12-19

### Исправлено
- **Фокус при Enter**: в поле номера Enter теперь не переводит фокус на поле времени. Фокус остаётся на номере. Tab работает как раньше.
- После нажатия Finish! фокус возвращается на поле номера.

## [1.1.0] - 2024-12-19

### Добавлено
- **Хронологический порядок в таблице**: записи сортируются по времени нажатия Finish! (свежие сверху).
- Поле `sequence` в FinishRecord для отслеживания порядка финишей.
- Место в таблице показывает рейтинг по времени, но порядок строк — хронологический.

## [1.0.1] - 2024-12-19

### Исправлено
- **Баг пробела**: Space теперь только запускает таймер (START). Остановка — только кнопкой STOP мышью.
- **Рекурсия при редактировании таблицы**: блокировка сигналов во время `_refresh_table()`, исправлен `EditableTableWidgetItem.__init__`.

## [1.0.0] - 2024-12-19

### Добавлено
- Инициализация проекта с современной структурой модулей
- Главное окно с крупным таймером (точность 0.1 сек)
- Кнопки управления таймером: START, STOP, RESET
- Горячие клавиши: Space (старт/стоп), Esc (сброс), Enter (финиш)
- Поле ввода номера участника (только цифры)
- Поле ввода ручного времени в формате HHH:MM:SS.sss
- Кнопка Finish! для записи финиша
- Таблица результатов с редактированием по двойному клику
- Навигация Tab между полями ввода
- Статусная строка с отображением состояния и ошибок
- Импорт файла регистрации из Excel (номер, ФИО, старт)
- Расчёт итогового времени с учётом персонального/общего старта
- Экспорт отчёта в Excel (красивое форматирование, медали 1-3 места) и CSV
- Автосохранение состояния каждые 30 секунд
- Восстановление состояния при запуске (участники, финиши, таймер, ввод)
- Централизованное логирование в файл + статус-бар
- Версионирование: версия в заголовке окна и имени exe
- Сборка в один exe-файл через PyInstaller
