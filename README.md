# FinalTime — Судейский хронометраж

Приложение для судей на соревнованиях: фиксация старта, финиша, ручного времени, штрафов и формирование отчётов.

## Особенности

- ⏱ **Точный таймер** — обновление каждые 0.1 сек, горячие клавиши (Space, Esc)
- 📋 **Импорт из Excel** — загрузка номеров, ФИО, стартовых времён
- 🏁 **Финиш** — ввод номера и ручного времени, мгновенный расчёт результата
- ✏️ **Редактируемая таблица** — двойной клик для изменения номера, времени, штрафов
- 📊 **Экспорт отчётов** — красивый Excel + CSV, сортировка по местам
- 💾 **Автосохранение** — восстановление после сбоя (участники, финиши, таймер)
- 📝 **Логирование** — файл логов + статус-бар с ошибками
- 📦 **Сборка в exe** — один файл для Windows 10/11

## Установка и запуск

### Из исходников (разработка)

```bash
# Клонирование
git clone <repo>
cd FinalTime

# Создание окружения через uv (рекомендуется)
uv venv
uv pip install -e ".[dev]"

# Или через pip
python -m venv venv
venv\Scripts\activate
pip install -e ".[dev]"

# Запуск
python main.py
```

### Сборка exe

```bash
# Установка зависимостей для сборки
uv pip install -e ".[build]"

# Сборка
pyinstaller --clean finaltime.spec
# или
python -m PyInstaller --clean --onefile --windowed --name "FinalTime_v1.2.0" finaltime/assets/icon.ico main.py
```

Готовый `FinalTime_v1.2.0.exe` будет в папке `dist/`.

## Использование

1. **Загрузите регистрацию** — `Файл → Загрузить регистрацию (Ctrl+O)` — выберите Excel-файл с колонками: Номер, ФИО, Старт (опционально)
2. **Запустите таймер** — кнопка `START` или `Space`
3. **На финише** — введите номер участника, при необходимости ручное время судьи, нажмите `Finish!` или `Enter`
4. **Просмотр/правка** — таблица результатов ниже, двойной клик по ячейке для редактирования
5. **Отчёт** — `Файл → Экспорт отчёта (Ctrl+S)` — выберите папку, получите `Report_FinalTime_v1.2.0.xlsx` и `.csv`

## Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| `Space` | Старт / Стоп таймера |
| `Esc` | Сброс таймера |
| `Enter` | Записать финиш (в полях ввода) |
| `Tab` | Навигация между полями |
| `Ctrl+O` | Загрузить регистрацию |
| `Ctrl+S` | Экспорт отчёта |

## Формат файла регистрации (Excel)

| Номер | ФИО | Старт (+MM:SS) |
|-------|-----|----------------|
| 1 | Иванов Иван Иванович | +00:30 |
| 2 | Петров Петр Петрович | |
| 3 | Сидоров Сидр Сидорович | +01:00 |

- Старт указывается как смещение от общего старта в формате `+MM:SS` или `+MM:SS.sss`
- Если старт не указан — используется общий старт (0)
- Столбцы можно перенастроить в коде (`ExcelImporter.col_number`, `col_name`, `col_start`)
